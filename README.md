# CodeAlpha Web Scraping Project

## Project Overview
This project uses Python to collect book information from the Books to Scrape demonstration website and save the extracted information in a structured dataset.

## Objectives
- Extract book titles, prices, availability, and ratings.
- Clean and organize the collected data.
- Create a CSV dataset.
- Categorize book prices and visualize the results.

## Technologies Used
Python, Requests, BeautifulSoup, Pandas, Matplotlib.

## Files Included
- `web_scraping.py`
- `books_dataset_5_pages.csv`
- `price_category_chart.png`
- Task 1 PDF report

## How to Run
Install the required libraries using:

`pip install requests beautifulsoup4 pandas matplotlib`

Run the script using:

`python web_scraping.py`

## Purpose
Completed for educational purposes as part of the CodeAlpha Data Analysis Internship.
